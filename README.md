# 🏥 Sistema Inteligente de Salud

## 📌 Descripción del Proyecto

El **Sistema Inteligente de Salud** es una aplicación web desarrollada con **HTML, CSS y JavaScript**, diseñada para demostrar cómo las matemáticas pueden aplicarse en el área médica mediante la **serie Fibonacci** y los **números primos**.

Este sistema fue creado con el propósito de mejorar el seguimiento de pacientes, fortalecer la seguridad de historias clínicas y demostrar el uso de algoritmos matemáticos aplicados a problemas del mundo real.

---

## 🎯 Objetivo del Proyecto

Desarrollar una plataforma web interactiva que permita aplicar conceptos matemáticos y programación para optimizar procesos relacionados con el área de salud.

---

# 🌐 Sistemas Implementados

## 🩺 1. Seguimiento Médico con Fibonacci

Este sistema utiliza la **serie Fibonacci** para organizar controles médicos progresivos de pacientes.

### Funcionalidades:
✅ Registro de paciente  
✅ Edad y diagnóstico médico  
✅ Generación automática de controles médicos  
✅ Historial clínico inteligente  
✅ Datos de prueba para el docente  

### Aplicación en la vida cotidiana:
Ayuda a mejorar el seguimiento de pacientes, organizar revisiones médicas y optimizar tratamientos.

---

## 🔐 2. Seguridad de Historias Clínicas

Este sistema emplea **números primos** para validar códigos médicos y reforzar la seguridad clínica.

### Funcionalidades:
✅ Verificación de códigos seguros  
✅ Validación de mínimo 8 dígitos  
✅ Ejemplo correcto y ejemplo de error  
✅ Recomendaciones de códigos seguros  

### Aplicación en la vida cotidiana:
Permite fortalecer la seguridad de información médica y proteger datos clínicos.

---

## 🧠 3. Sistema Inteligente de Seguimiento

Sistema avanzado que combina **Fibonacci + números primos**.

### Funcionalidades:
✅ Seguimiento médico inteligente  
✅ Validación de seguridad del código  
✅ Identificación de Fibonacci primos  
✅ Nivel de riesgo médico  
✅ Historial clínico avanzado  

### Aplicación en la vida cotidiana:
Ayuda a mejorar el control de pacientes y reforzar la seguridad de información médica.

---

## 🧠 Algoritmos Utilizados

### Serie Fibonacci
Secuencia matemática donde cada número se obtiene sumando los dos anteriores.

Ejemplo:

```text
1, 1, 2, 3, 5, 8, 13, 21...
```

### Números Primos
Números divisibles únicamente entre 1 y sí mismos.

Ejemplo:

```text
2, 3, 5, 7, 11, 13, 17...
```
