Seguridad de Historias Clínicas

Aplicación de números primos para reforzar la seguridad de códigos médicos.

🔐 ¿Qué problema resuelve este sistema?

En hospitales y centros médicos es importante proteger la información clínica de los pacientes. Muchas veces, los códigos médicos pueden ser débiles o fáciles de identificar, lo que puede representar riesgos en la seguridad de datos hospitalarios.

Este sistema propone el uso de números primos para evaluar códigos médicos y reforzar la protección de historias clínicas.

❤️ ¿Cómo beneficia a la vida cotidiana?

Permite fortalecer la seguridad de información médica, ayudando a hospitales y clínicas a manejar códigos más seguros para proteger datos de pacientes.

🧠 ¿En qué algoritmo se basa?

El sistema utiliza números primos, que son aquellos que solamente pueden dividirse entre 1 y sí mismos.

Ejemplo:

2, 3, 5, 7, 11, 13, 17...

Se emplea JavaScript junto con ciclos repetitivos (for) para verificar si un número tiene más divisores, determinando así si un código médico es seguro o poco seguro.

Código médico: 10000019


❌ Ejemplo Incorrecto
